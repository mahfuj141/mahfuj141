## 🚀 Highlighted Projects

**⚡ SouthStack Code AI — In-Browser LLM *(In Progress)***

A fully offline AI coding assistant powered by a **1.5B parameter LLM running entirely inside the browser tab** — no server, no API key, no internet required after first load. Built with WebGPU for on-device hardware-accelerated inference.

* Real-time token streaming with a live typing cursor in a custom chat UI
* Model weights (~1 GB) cached in the browser — loads instantly on repeat visits
* Solved `SharedArrayBuffer` requirement via custom Vite COOP/COEP security headers
* Full markdown + fenced code block rendering inside the chat interface
* Handcrafted dark terminal-style UI using vanilla HTML/CSS/JS

---

**🎓 Alumni Network & Management System**

A full-stack **university alumni platform** built with PHP and MySQL, featuring a real relational database backend and a complete set of social and career management tools.

* Modules: alumni directory, job board, internship listings, events, achievements, communication feed, employment tracker
* Session-based authentication system — register, login, logout with security layer
* Fully normalized relational schema designed from scratch, no data redundancy
* Modular PHP page routing with a clean `db.php` connection layer

---

**📚 Library Management System** `CSE215`

A **Java-based Library Management System** applying core OOP principles throughout.

* Manage books, members and borrow/return transactions in a structured flow
* Class hierarchy using inheritance, polymorphism and encapsulation — no God classes
* Persistent data storage across sessions via file I/O

---

**🏅 Paris Olympics 2024 — Data Structure Project**

A **C++ application** that models and queries real Paris 2024 Olympic Games data using custom-built data structures — not relying on STL shortcuts.

* Hand-rolled sorting, searching, and tree/graph data structures
* Query interface for medal tallies, event schedules, and country rankings
* Real-world dataset used to ground abstract DSA concepts into practice
