## 🚀 Highlighted Projects

**⚡ SouthStack Code AI — In-Browser LLM *(In Progress)***

A fully offline AI coding assistant powered by a **1.5B parameter LLM running entirely inside the browser tab** — no server, no API key, no internet required after first load. Built with WebGPU for on-device hardware-accelerated inference.

* Real-time token streaming with a live typing cursor in a custom chat UI
* Model weights (~1 GB) cached in the browser — loads instantly on repeat visits
* Solved `SharedArrayBuffer` requirement via custom Vite COOP/COEP security headers
* Full markdown + fenced code block rendering inside the chat interface
* Handcrafted dark terminal-style UI using vanilla HTML/CSS/JS
